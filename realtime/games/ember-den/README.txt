Ember Den

Explore a firelit cave and use an axe to defeat three approaching eight-legged spiders.
Defeat all three spiders. Health reaches zero from spider bites.

Select this game from the workbench library. Preview: /ext/game2v/play/ember-den

WASD: move
Arrow keys: aim
F: swing axe
Space: jump
P / Escape: pause
Enter: restart

Created with the repository edengolem skill using spiders as the gameplay reference.
first-frame.png: proxy image rendered from the game scene. cover.png / poster.png: FLUX artwork generated from first-frame.png (regenerate after any scene change).
artwork.json: caption, seed and generation settings. validation.json: checks.
