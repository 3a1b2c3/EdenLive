Iron Colossus

Rampage as a single giant reptile, breathe flame and stomp to demolish a defended city.
Demolish all six city towers. Health reaches zero from defense shells.

Select this game from the workbench library. Preview: /ext/game2v/play/iron-colossus

WASD: move
Arrow keys: aim / turn
F: breathe fire
Space: stomp
P / Escape: pause
Enter: restart

Created with the repository edengolem skill using kaiju-rampage as the gameplay reference.
first-frame.png: proxy image rendered from the game scene. cover.png / poster.png: FLUX artwork generated from first-frame.png (regenerate after any scene change).
artwork.json: caption, seed and generation settings. validation.json: checks.
