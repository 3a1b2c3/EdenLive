Jade Duel

Defeat a martial artist with combos, guard, uppercut, energy wave and dash.
Reduce the opponent health to zero. Player health reaches zero.

Select this game from the workbench library. Preview: /ext/game2v/play/jade-duel

A / D: move
F: punch combo
G: guard
Space: jump
E: uppercut (15 energy)
R: wave (30 energy)
Shift: dash (10 energy)
P / Escape: pause
Enter: restart

Created with the repository edengolem skill using arcadeduel as the gameplay reference.
first-frame.png: proxy image rendered from the game scene. cover.png / poster.png: FLUX artwork generated from first-frame.png (regenerate after any scene change).
artwork.json: caption, seed and generation settings. validation.json: checks.
