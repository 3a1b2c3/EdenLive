Warehouse Sokoban

Push two wooden boxes onto the two marked goals, one tile at a time; boxes cannot be pulled or pushed in pairs.
Both boxes occupy goal pads. A box is pushed into a wall corner that is not a goal.

Select this game from the workbench library. Preview: /ext/game2v/play/warehouse-sokoban

WASD / Arrow keys: move and push
P / Escape: pause
Enter: restart

Created with the repository game-prototype-turbo skill.
first-frame.png: proxy image rendered from the game scene. cover.png / poster.png: FLUX artwork generated from first-frame.png (regenerate after any scene change).
artwork.json: caption, seed and generation settings. validation.json: checks.
