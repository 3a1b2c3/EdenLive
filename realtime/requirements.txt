# Runtime for the realtime/ serving path, pinned from the environment it was
# verified in. Install from realtime/:
#
#   pip install torch==2.13.0 torchvision==0.28.0 \
#       --index-url https://download.pytorch.org/whl/cu130
#   pip install --no-deps -e ./flashdreams -e ./apps/cam2v \
#       -e ./integrations_v2/eden
#   pip install -r requirements.txt
#
# torch and torchvision are deliberately absent here: a plain `pip install -r`
# would resolve them from PyPI and can land on a CPU build. Install the CUDA
# wheels first, from the index matching your driver (cu130 above; cu128 is
# https://download.pytorch.org/whl/cu128), and keep the torchvision minor in
# step with torch. The serving code falls back to a PIL image processor when
# torchvision is missing, and that fallback crashes on CUDA tensors.
#
# This tree's own packages are not on PyPI, and a requirements line cannot
# carry `--no-deps`, so they are installed separately. Without it pip would try
# to fetch `flashdreams` from PyPI while installing the packages that depend on
# it. Order matters: each one imports the one before it.
#
# Not included, and not needed to serve game2v: the local Dear ImGui window
# (imgui-bundle, slangpy), which no game2v config imports.
